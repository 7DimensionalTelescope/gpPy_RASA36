# gpPy_RASA36

CCD data-reduction pipeline for the RASA36 telescope: calibration (bias/dark/flat),
astrometric solving, stacking, photometry, image subtraction, and transient search.

## Acknowledgment

This pipeline builds on work contributed by multiple members of the IMSNG/RASA36
collaboration over time. It is currently maintained by Youngpyo Hong, who adapted and
extended the original gpPy pipeline for RASA36 (see `CHANGELOG_pipeline.md` for what
changed relative to the original). If you contributed code that ended up here and would
like to be credited by name, please open an issue or PR.

## Usage

See [CLAUDE.md](CLAUDE.md) for run commands, pipeline stage sequence, and known failure
signatures.

```bash
python IMSNG_Routine_RASA36.py <input_folder> [ncores] [--no-stack]
```

## Notes

- `keys.dat` (Slack bot token) is intentionally excluded — create your own with:
  ```
  name key
  slack xoxb-...
  ```
- Large run artifacts (`log/`, `refcat/`, intermediate FITS/XML outputs) are excluded via
  `.gitignore` and are regenerated by each pipeline run.
